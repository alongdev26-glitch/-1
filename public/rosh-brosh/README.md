# ראש בראש · אב-טיפוס

משחק טריוויה של רשימות בעברית, מול יריב ממוחשב. בלי build ובלי שרת.

- משחק: `npm run dev` ואז `/rosh-brosh/` (או `python3 -m http.server` בתוך התיקייה הזאת)
- בדיקות: `npx vitest run public/rosh-brosh`

## איך המשחק עובד
- משחק = עד 5 סיבובים, הראשון שמנצח 2 סיבובים לוקח. לפני כל סיבוב 6 שניות לאשר או להחליף שאלה (8 🪙).
- בסיבוב יש 30 שניות להקליד כמה שיותר תשובות לשאלה ("דברים שנוטים לאבד"). כל תשובה נספרת למי שמצא אותה ראשון. מי שמצא יותר, זוכה.
- עזרים: עוד 10 שניות (6 🪙), ג'וקר שחושף תשובה (12 🪙).
- אנרגיה ⚡ (5, אחת חוזרת כל 10 דקות), מטבעות 🪙, יהלומים 💎 וגביעים 🏆. הכול נשמר ב-localStorage. הרכישה בכסף אמיתי עדיין מדומה.

## קבצים
| קובץ | תפקיד |
| --- | --- |
| `questions.js` | 50 שאלות-רשימה, ולכל תשובה שם ראשי ונרדפות |
| `checker.js` | בדיקת תשובות סלחנית: ניקוד, מלא/חסר, ה הידיעה, אותיות סופיות, ק/כ ט/ת ע/א, שגיאת הקלדה אחת או שתיים |
| `bot.js` | היריב: שם, תמונה, גביעים קרובים, ותזמון ניחושים בקצב אנושי |
| `economy.js` | אנרגיה, מחירים, פרסים ובחירת שאלה |
| `game.js` | המסכים (ה-HTML וה-CSS של Stitch, עם Tailwind) |
| `style.css` | ה-CSS המותאם מ-Stitch |
| `tailwind.css` | נבנה אוטומטית. אחרי שינוי מחלקות ב-`game.js`: `npx tailwindcss@3.4.17 -c tailwind.config.cjs -i tailwind.src.css -o tailwind.css --minify` בתוך התיקייה |

## הצעד הבא
מולטיפלייר אמיתי (Firebase או Supabase) שמחליף את הבוט כשיש שחקן פנוי, וטבלת מובילים אמיתית. כדי להוסיף שאלות, מוסיפים ל-`questions.js` ושמות חלופיים ליד כל תשובה.
