# ראש בראש · אב-טיפוס

משחק טריוויה של רשימות בעברית, מול יריב ממוחשב. בלי build ובלי שרת.

- משחק: `npm run dev` ואז `/rosh-brosh/` (או `python3 -m http.server` בתוך התיקייה הזאת)
- בדיקות: `npx vitest run public/rosh-brosh`

## איך המשחק עובד
- משחק = עד 5 סיבובים, הראשון שמנצח 2 סיבובים לוקח. לפני כל סיבוב 6 שניות לאשר או להחליף שאלה (8 🪙).
- הסיבוב בתורות, וכל שחקן מתחיל עם 3 חיים. לכל תור 10 שניות. תשובה נכונה מעבירה את התור ליריב. טעות או סוף זמן מורידים חיים ומעבירים את התור, ומי שנשאר בלי חיים מפסיד את הסיבוב. אם נגמרו התשובות, מי שנתן את האחרונה מנצח, ולא מי שמצא יותר. אי אפשר להקליד כשלא התור שלך.
- עזרים: עוד 10 שניות (6 🪙), ג'וקר שחושף תשובה (12 🪙).
- אנרגיה ⚡ (5, אחת חוזרת כל 10 דקות), מטבעות 🪙, יהלומים 💎 וגביעים 🏆. הכול נשמר ב-localStorage. הרכישה בכסף אמיתי עדיין מדומה.

## קבצים
| קובץ | תפקיד |
| --- | --- |
| `questions.js` | 50 שאלות-רשימה, ולכל תשובה שם ראשי ונרדפות |
| `checker.js` | בדיקת תשובות סלחנית: ניקוד, מלא/חסר, ה הידיעה, אותיות סופיות, ק/כ ט/ת ע/א, שגיאת הקלדה אחת או שתיים |
| `bot.js` | היריב: שם, תמונה, גביעים קרובים, ותזמון ניחושים בקצב אנושי |
| `net.js` | התאמה וחיבור אונליין: PeerJS (משבצות המתנה בשרת הציבורי) או BroadcastChannel לבדיקות (`?net=bc`) |
| `protocol.js` | הודעות בין שני הטלפונים והיפוך נקודת המבט |
| `rules.js` | חוקי הסיבוב: חיים, תורות ומי מנצח |
| `icons.js` | אייקוני SVG |
| `privacy.html` | מדיניות פרטיות |
| `economy.js` | אנרגיה, מחירים, פרסים ובחירת שאלה |
| `game.js` | המסכים (ה-HTML וה-CSS של Stitch, עם Tailwind) |
| `style.css` | ה-CSS המותאם מ-Stitch |
| `tailwind.css` | נבנה אוטומטית. אחרי שינוי מחלקות ב-`game.js`: `npx tailwindcss@3.4.17 -c tailwind.config.cjs -i tailwind.src.css -o tailwind.css --minify` בתוך התיקייה |

## הצעד הבא
מולטיפלייר אמיתי (Firebase או Supabase) שמחליף את הבוט כשיש שחקן פנוי, וטבלת מובילים אמיתית. כדי להוסיף שאלות, מוסיפים ל-`questions.js` ושמות חלופיים ליד כל תשובה.

## גרסאות ומטמון
אחרי כל שינוי מעלים את המספר ב-`?v=` ב-`index.html` וב-5 הייבואים בראש `game.js`, ואת התווית ב-`home()`. כך הטלפון לא נשאר עם קבצים ישנים.

## מצבי משחק
- **שחק כעת:** אונליין מול שחקן אקראי. אם לא נמצא יריב תוך 20 שניות (`?search=N` לשינוי), משחקים מול בוט.
- **שניים על מכשיר אחד:** כל שחקן מקליד בתורו. בלי אנרגיה, גביעים או מטבעות.
- **מול הבוט.**
- בדיקת אונליין בלי אינטרנט: לפתוח שתי לשוניות עם `?net=bc` ולחצות "שחק כעת" בשתיהן.

## לוגו
הלוגו נוצר ב-Google Stitch: מגן זהב עם אריה וזאב, ברק וסרט עם השם. `icon-1024.png` הוא המקור (פינות שקופות), ממנו נוצרו `icon-512.png` (לחנות Google Play), `icon-192.png`, `apple-touch-icon.png` ו-`favicon.png`. `manifest.webmanifest` מאפשר להוסיף את המשחק למסך הבית בטלפון.
