# GOAL RUSH ⚽

משחק כדורגל 1v1 לטלפון (Canvas + TypeScript + Vite), בנוי 1:1 לפי פרומפט העיצוב.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בדיקת טיפוסים + בנייה ל-dist/
npm test         # פיזיקה, בוט וחנות (Vitest)
```

- **משחק:** גוררים אחורה מכל מקום במסך ומשחררים כדי לבעוט (קשת מקווקוות + טבעת עוצמה). גול = 10 × קומבו, כדור האבטיח מכפיל x2. ראשון ל-50 מנצח. ב-Global Competition ראשון ל-2 סיבובים מתוך 3.
- **ארבע זירות** מתחלפות: Shoot and Score, 1v1 Battles, Global Competition, Become a Superstar.
- **Customization:** לשוניות Ball / Player / Add-on, קנייה במטבעות (נשמר ב-localStorage).
- **Showcase:** חמשת מסכי הפרומו עם הבאנרים (משחק דמו חי).
