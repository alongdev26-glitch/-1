# Avatar Arena

משחק קרבות בסגנון Smash Bros עם דמויות מאווטאר. Phaser + Vite. (פרויקט נפרד מ"דיל סיטי".)

```bash
cd avatar-arena
npm install
npm run dev
```

- `src/data/characters.js` – כל הדמויות והיכולות. מוסיפים דמות = מוסיפים אובייקט.
- `src/scenes/` – תפריט, בחירת דמות, קרב.
- בקרה: חצים/WASD, J התקפה, K יכולת. בטלפון מופיעים כפתורי מגע.

## מצב
שלב 1 (בסיס): ארבע דמויות (אנג, קטרה, טוף, זוקו), זירה אחת, קרב נגד מחשב עם אחוזי נזק, הדחה ו-3 חיים.
